# Care Management Game

A simple browser-based care management game where you balance health, mood, energy, stress, and support resources while guiding a patient through a 14-day care plan.

## How to run

Open `index.html` directly in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Game loop

Each day, choose one action to support the patient:

- Administer medication
- Prepare balanced meals
- Social check-in
- Gentle movement
- Rest and recovery
- Handle paperwork

Your goal is to keep the patient stable and improve the care score by the end of 14 days.
